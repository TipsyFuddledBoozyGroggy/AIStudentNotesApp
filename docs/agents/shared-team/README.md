# Shared agent team (canonical copy)

These six files are the team. The live copies belong in the user-level `~/.claude/agents/` folder (`%USERPROFILE%\.claude\agents` on Windows) so every project on that computer sees them. On a new computer, copy these files there. If you edit one, update both places.

Models: senior-engineer-fable = fable (high effort), senior-engineer-opus = opus (high effort), architect = opus (high), junior-dev = haiku, product-owner and qa-engineer = sonnet.
