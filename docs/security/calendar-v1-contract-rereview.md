## Answers to the Lead's R-items (section 20)

- **R6 content-free record**: acceptable as "content-free" (event id, generation, calendar target id, last-used time; no title, date, course, item key or fingerprint). It is not anonymous: it is scoped to the user through the calendar target, and the event id is a hash of `itemKey`, which is a hash of the syllabus and item ids that may survive in audit rows for up to 400 days, so a database holder could confirm "this deleted syllabus once produced an event". That reveals existence and a rough time, not content. LOW N-1.
- **R7 J27/Q14 (records never used to delete events)**: security-safe. It is the only way to honour PO-10a, since a record cannot show an edit. It contradicts PO-9o's "can still remove its own events later" and PO-10o's wording (X14/X15); that is a PO decision, not a defect. Info I-1.
- **R14 resume run**: a new external-write path that overwrites a student edit. Bound to a preview digest, an `Idempotency-Key`, the eligibility re-check, and a deliberate action (8.6). Acceptable with N-2.
